# Provenance

This skill is vendored, unmodified, from the third-party open-source project
[DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)
(commit `356918eba965ee1eac64bd3a7f0dd02108350de5`, `skills/ponytail/SKILL.md`),
licensed under the MIT License (see `LICENSE` in this directory).

It is **not** an official Anthropic skill. Only the core `ponytail` skill
(SKILL.md) was vendored here — the upstream repository also ships companion
skills (`ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`,
`ponytail-help`) plus optional Node.js hooks / an MCP server for
always-on activation, none of which are included in this install.
